# Logos — библиотека знаний

Архитектура, иерархия страниц и компонентов: [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md).

**Logos** — самостоятельный публичный сайт со своим доменом и дизайном. Рубрики, публикации, медиа и управление контентом предоставляет **JSInteractive**. Отдельная административная система Logos не нужна.

## Дизайн и страницы

Светлая палитра с изумрудным акцентом и сдержанным золотом задаётся в `src/App.vue`. Интерфейс адаптирован для мобильных устройств, поддерживает клавиатурную навигацию и уменьшение анимации.

| Маршрут | Назначение |
| --- | --- |
| `/` | Главная: каталог тем, новые материалы, подход к исследованию |
| `/catalog` | Рубрики и поиск по загруженному списку |
| `/catalog/:catName` | Список материалов рубрики и локальный поиск |
| `/catalog/:catName/:slug` | Текст, аннотация, оглавление, библиография |
| `/lecture/...` | Обратная совместимость со старыми адресами через клиентские редиректы |

Поиск пока выполняется по уже загруженным данным, а не по всей базе. Оглавление статьи строится из заголовков H2/H3 и не меняет сохранённый HTML на сервере.

## Локальная разработка

Создайте файл `.env.local`:

```env
VUE_APP_SERVER=https://jsinteractive.ru
VUE_APP_SITE_KEY=logos
```

```bash
npm ci
npm run verify
npm run serve
```

Сборка:

```bash
npm ci
npm run verify
npm run build
```

## Связь с JSInteractive

Публичный Vue-клиент обращается только к GET API:

```text
/api/public/v1/sites/logos/bootstrap
/api/public/v1/sites/logos/categories
/api/public/v1/sites/logos/publications
/api/public/v1/sites/logos/publications/<slug>
```

В JSInteractive должен существовать активный сайт `logos`. Origin отдельного домена Logos необходимо добавить к разрешённым origin публичного API. Создание, редактирование, публикация материалов и работа с медиа выполняются в JSInteractive.

Версионированные профили `logos.article@1` и `logos.lecture@1` позволяют отображать аннотацию, ключевые слова, библиографию и автора. Отсутствующие необязательные поля скрываются. Приватные ключи, admin-cookie и API-секреты во frontend не передаются.

## Качество кода

Используем единый формат **Prettier 2.8.8** и проверку **ESLint 8**.
Все команды запускаются после `npm ci`.

```bash
npm run format        # автоматически отформатировать исходники
npm run format:check  # проверить форматирование без изменений
npm run lint          # проверить JavaScript и Vue
npm run lint:fix      # исправить поддерживаемые правила ESLint
npm run verify        # архитектурные проверки и unit-тесты
npm run check         # все проверки и production-сборка
```

CI выполняет линтинг, проверку форматирования, unit-тесты и сборку. Содержимое CSS не меняет цветовую палитру или логику интерфейса при форматировании.

SEO-метаданные централизованы: чистые функции описаний находятся в `src/seo/descriptors.mjs`, запись в DOM — в `src/seo/index.js`. Оглавление проверяется отдельно через `src/domain/toc.mjs`.

## Развёртывание

Результат `npm run build` из `dist/` размещается на отдельном статическом web-сервере. Для прямого открытия страниц Vue Router сервер возвращает `index.html` на неизвестных frontend-маршрутах. HTTPS, CSP, CORS и домен Logos настраиваются отдельно.

При миграции существующих публичных URL `/lecture/...` желательно настроить **HTTP 301** на сервере, потому что нынешние клиентские редиректы обслуживают прежде всего посетителей браузера. SEO-метаданные сейчас формируются во Vue; для поисковых роботов без выполнения JavaScript понадобится SSR или пререндеринг.

## Состояния загрузки и анимации

Все публичные страницы используют общие компоненты `LoadingSkeleton` (скелетоны каталога, списка и статьи) и `AsyncState` (пустой список, нулевой результат поиска, ошибка и повторная загрузка). Рубрики и последние публикации главной страницы загружаются независимо.

Маршруты, мобильное меню, смена состояний и перестановка карточек при фильтрации анимированы через Vue `Transition` / `TransitionGroup`. Общие эффекты находятся в `src/styles/states.css`. При `prefers-reduced-motion: reduce` движение отключается. Содержимое по-прежнему поступает исключительно из публичного API JSInteractive.

Ручная приёмка: ограничить скорость сети в DevTools и проверить скелетоны на всех страницах; воспроизвести пустые ответы, отсутствие результатов поиска и ошибки запросов; проверить кнопку «Повторить». Также проверить быстрые переходы, смену рубрик, мобильное меню, прямые ссылки, оглавление длинной статьи и режим уменьшения движения.
